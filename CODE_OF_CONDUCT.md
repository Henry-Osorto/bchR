# Convivencia del proyecto

Colabora con respeto, sin acoso, discriminación, ataques personales ni divulgación
de información privada. Discute ideas, evidencia y código; evita atribuir intenciones.
Acepta correcciones y señala incertidumbres o límites de los resultados.

No publiques credenciales ni datos personales de terceros. El mantenedor puede
moderar contenido, pedir cambios o cerrar interacciones que incumplan estas reglas.
Las decisiones se tomarán según el contexto, evitando difundir información sensible.

Para comunicar un problema de convivencia, escribe a henry.osorto@unah.edu.hn
con una descripción breve. No hay un plazo de respuesta garantizado. Este es un
código de convivencia breve del proyecto, no una declaración de adhesión a un
estándar externo de certificación.
